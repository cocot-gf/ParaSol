# Echo State Network(ESN)を使った時系列データの学習
これまでに出てきた教師あり学習ではKey(X)とValue(T)の値のみに着目して学習・推論を実行していましたが、
Solist-AIのESNを使った時系列モデルではKeyとValueの他に過去の学習・推論の【状態】を内部保持することで、
特定の並びでデータが入ってきたときの振る舞いを表現することができます。

ESNやリザバーコンピューティングは高速だという文献を多々見かけますが、誤差逆伝播(BP)と比較して高速ということであって、ESNの基本形であるELMと比較すると高速にはなりません。
Solist-AIではESNなしの純粋なELMとESNありを比較すると、ESNありの方が1～2割程度遅くなります。
時系列モデルを扱わない限りESNを有効にする意味はありませんし、時系列ではない(サンプル順序に関連性のない)データの場合は、正しい推論結果が出てこなくなる可能性があります。

※お断り  
ロームのアプリケーションノートやサンプルソースにはESNを使う例がほとんど記載されていません。具体的な説明や応用アプリケーションの十分な説明ができない点をご了承ください。

## Echo State Network向けの初期化手順
Echo State Networkを有効にするには、scaleGammaを0以外の値に設定するだけOKです。

「どういう動きをするのか?」の例のように波形をFFT処理せずそのまま記憶させる場合は、入力ノード数を1にしてサンプリングごとに学習させます。
FFTの周波数情報のような多点を一度に学習させることもできるでしょうが、隠れ層のサイズが不足すると十分な再現出力を得られないかもしれません。

| パラメータ | 設定値 |
|-|-|
|inputSize|キーになるデータセットのサイズに合わせて任意。|
|hiddenSize|必要RAMサイズと計算時間が許す範囲で165以下の大きめの値。<br>少なすぎると再現性が減り、大きすぎると必要RAMと計算時間が飛躍的に増大する。|
|outputSize|結果として得たいデータセットのサイズ。|
|forgettingFactor|1|
|activationFunction|任意、3(tanh)から試すのがオススメ。|
|lossFunction|任意|
|seed|任意|
|scaleAlpha|0(Auto)か、とりあえず LN(10^15) / inputSize|
|scaleGamma|0以外の値でEcho State Networkが有効になる。<br>この値はEcho State Property(ESP)を持たせるために <img width="108" height="37" alt="aa" src="https://github.com/user-attachments/assets/f6caaf4b-4656-4ecd-828e-2f639aa901b1" /> の式を使って導いた値を基準として設定します。この値の経験則は、大きくしすぎると推論時に入力Xへの追従性が悪くなり、小さくしすぎると入力Xの変化に敏感かつ過度に反応するようになります。|
|leakRate|任意、0.5からスタート。|
|L2Param|0または任意、0.5～10あたりを入れると再現性・学習速度・発散耐性が上がり、hiddenSizeを大幅に縮小できる。|

ESNでは過去の状態を保持するために、ELMの隠れ層に赤線の自己フィードバックの重みγ(ガンマ)が追加されます。
学習・推論の隠れ層を計算するタイミング(ここ重要)でγの値を更新することで、内部状態として過去の経歴を含んだ出力を得られる仕組みになっています。

## 学習の手順
教師あり学習と同じように入力データXと教師データTをペアで学習させてください。  
<br>

    学習クリア  
    リザバークリア  

    <学習回数ループ>  
       学習 x[inputSize], t[outputSize]
    <ループ終了> 

* 学習前にリザバークリアを実行して内部状態をリセットしてください。
* 内部状態を持ちますので、教師なし・教師あり学習のような【追加学習】はできないと思ってください。
* 正弦波のような周期をもつ波形は、2周期以上学習させると推論精度が上がります。逆に、周期の途中で学習を終えると推論精度が下がります。
* 未来の予測をする場合は、想定している未来の値を教師データに入れて学習させます。未来の値がわからない場合は、バッファリングした過去のデータを入力データ、最新のデータを教師データとして設定すると、結果として時間差で未来の予測ができることになります。
* その他の要点は教師なし・教師あり学習と同じです。

### 学習中にLossや推論Y出力を取得する場合の注意点
教師なし・教師あり学習のように学習ループ中に推論+Loss取得を含めると、重みγが2度計算されるので正しく学習できません。
ESNの学習都度にLossを要求される局面は少ないと思いますが、どうしてもLossや推論のY出力が必要な場合は、下記のように推論前にγ(リザバー)を退避し、推論終了後にγを書き戻してください。

    <学習回数ループ>  
       学習 x[inputSize], t[outputSize]
       
       ODL_GetReservoir
        推論 x[inputSize], t[inputSize]  
        Loss取得 (任意)  
        推論結果y取得 (任意)  
       ODL_SetReservoir
    <ループ終了>
